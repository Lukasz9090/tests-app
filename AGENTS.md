# Agent notes for this repository

Tests in this repository may be generated by **tc-agent**
(`.github/agents/tc-agent/`). Its conventions — how generated tests are marked,
what a characterization test means, placeholders, naming, structure, time and
determinism — travel with the agent in
`.github/agents/tc-agent/tc-test-conventions.md`. This file adds no test rules
of its own, so the agent works here exactly as on any other repository.

Reading a generated test:

- a Javadoc with `tc-agent: generated` marks a method written by the agent;
- `tc-agent-characterizes: <Class>@<sha>` means the test froze what the code did at that
  commit, bugs included — when it fails after a change, first ask whether the
  old behaviour was right, not how to make the test green;
- an empty `@Disabled("AI deferred: …")` method with `tc-agent-deferred` is a scenario
  deliberately left untested; delete it (or fix the seam it names) to let the
  agent try again.

Branches the agent must never commit to (read by `tc_orchestrate.py finish
--commit`; without this line only `master` is protected):

tc-agent-protected-branches: master
